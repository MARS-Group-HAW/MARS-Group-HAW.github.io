# Ready to use scenarios

This section describes ready-to-use scenarios of the SmartOpenHamburg model. All scenarios ("boxes") are part of the public [model-soh repository](https://github.com/MARS-Group-HAW/model-soh) and can be started with `dotnet run` from their folder (see [Quick Start](../getting-started.md)).

Scenarios with a detailed description on this website:

* :ship: [FerryTransfer](ferry_transfer.md)
* :bike: [Green4Bikes](green_4_bikes.md)

Further scenarios in the repository (see the README in each folder):

* [SOHTravellingBox](https://github.com/MARS-Group-HAW/model-soh/tree/master/SOHTravellingBox) – agents travelling within the area of Hamburg Dammtor
* [SOHCitizenDailyPlanBox](https://github.com/MARS-Group-HAW/model-soh/tree/master/SOHCitizenDailyPlanBox) – `Citizen` agents following precomputed daily plans
* [SOHBicycleRealTimeBox](https://github.com/MARS-Group-HAW/model-soh/tree/master/SOHBicycleRealTimeBox) – cyclists in Hamburg-Harburg, similar to Green4Bikes
* [SOHBusBox](https://github.com/MARS-Group-HAW/model-soh/tree/master/SOHBusBox) and [SOHTrainBox](https://github.com/MARS-Group-HAW/model-soh/tree/master/SOHTrainBox) – walking agents using bus or train lines
* [SOHChristmasMarketBox](https://github.com/MARS-Group-HAW/model-soh/tree/master/SOHChristmasMarketBox) – pedestrian dynamics at a Hamburg Christmas market
* [SOHLogisticsBox](https://github.com/MARS-Group-HAW/model-soh/tree/master/SOHLogisticsBox) and [SOHTruckFuelAlternativeBox](https://github.com/MARS-Group-HAW/model-soh/tree/master/SOHTruckFuelAlternativeBox) – truck logistics and routing in Germany
* [CarletonDrivingBox](https://github.com/MARS-Group-HAW/model-soh/tree/master/CarletonDrivingBox) – cars leaving Carleton University (Ottawa) during an evacuation

The repository contains further experimental boxes.
